# Rusça

Türkler için Rusça: günün kelimesi (Türk harfleriyle okunuş), kart kaydırma ve kısa pratik.

## Çalıştırma

Windows’ta Android veya Chrome:

```powershell
C:\Users\Legion\flutter\bin\flutter.bat pub get
C:\Users\Legion\flutter\bin\flutter.bat run
```

iOS derlemesi ve kilit ekranı widget’ı yalnızca Mac + Xcode ile açılır. Widget hedefi `ios/RuscaWidget` içindedir (iOS 16+). App Group: `group.com.rusca.app`.

iPhone’da kelime saatin yerine geçmez. Kilit ekranına uzun bas → Özelleştir → Kilit Ekranı → widget ekle → Rusça. Satır, saatin üstündeki tarih satırına gelir. Dikdörtgen kart saatin altına gelir.

## Android widget

Ana ekranda boş alana uzun bas → Widget’lar → Rusça → Günün kelimesi.

Uygulama kelimeyi değiştirdiğinde widget aynı metni gösterir: okunuş, Kiril, Türkçe.
